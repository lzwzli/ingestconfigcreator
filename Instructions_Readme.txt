To use IngestConfigCreator:
1. Double-click on Run_IngestConfigCreator.bat
2. Choose the source type
3. Enter the parameter values as prompted.

Any required parameters that are not provided will be re-prompted.

The output report will contain a command with the parameters provided as arguments for future runs.
